## 1. はじめに

Raise timeline は、文章と画像を投稿して、フォローした人の投稿を読むアプリです。いいね・コメントで反応できます。

- **インプレッション数（何人に見られたか）は出しません。リツイート（ほかの人の投稿の共有）もありません。** 数字や拡散を気にせず投稿できます
- 投稿は、ログインしている人なら誰でも見られます。鍵アカウント（見せる人を選ぶ機能）はありません
- 通知・ダイレクトメッセージ・投稿の検索はありません。検索できるのはユーザーだけです

### 1.1 使える環境

| 機器 | ブラウザ |
| --- | --- |
| パソコン（Windows 11） | Google Chrome、Microsoft Edge、Mozilla Firefox |
| パソコン（macOS 14 以降） | Safari、Google Chrome |
| iPhone（iOS 17 以降） | Safari |
| Android 14 以降 | Google Chrome |

- どれも最新版を使ってください。アプリのインストールは要りません。ブラウザで URL を開きます
- インターネットへの接続が必要です。つながっていないときは、画面の上に「インターネットに接続されていません。接続を確認してください。」と出ます。つながると消えます
- 費用を抑えるため、使わない間はサーバーを止めています。止めている間に開くと「Raise timeline は止めています」と出ます。動かしている時間に開き直してください

### 1.2 画面の見方

ログインした後の画面は、どれも一番上にヘッダーがあります。

```
┌──────────────────────────────────────────────────────────┐
│ Raise timeline   [🔍 ユーザーを検索      ]  (た) ログアウト │
└──────────────────────────────────────────────────────────┘
```

| 部分 | できること |
| --- | --- |
| Raise timeline | 押すとタイムラインに戻る |
| 🔍 ユーザーを検索 | ユーザーを探す（7 章） |
| (た)（自分のアイコン） | 押すと自分のプロフィールを開く |
| ログアウト | ログアウトする（2.3） |

スマートフォンなど画面の幅が狭いときは、アプリ名が「RT」になり、検索欄は 🔍 のボタンだけになります。🔍 を押すと検索欄が開きます。

## 2. アカウント

### 2.1 アカウントを作る

1. URL を開き、ログイン画面の「アカウントを作る」を押す
2. 次の 4 つを入れて「登録する」を押す

| 項目 | 決まり |
| --- | --- |
| ユーザー ID | 3〜15 文字の半角英数字と「_」。ほかの人と同じ ID は使えません（大文字と小文字の違いだけでも同じ ID とみなします）。後から変えられません |
| 表示名 | 1〜30 文字。画面に名前として出ます。後から変えられます |
| パスワード | 英字と数字を両方含む 8〜64 文字の半角文字。記号・空白も使えます |
| パスワード（確認） | パスワードと同じものをもう一度 |

- 条件に合わない項目があると、その入力欄の下に理由が出ます
- 登録するとそのままログインし、タイムラインが開きます
- メールアドレスは登録しません。**パスワードを忘れたときに再発行する方法はありません。** 忘れたときは、新しいアカウントを作ってください

### 2.2 ログインする

1. ログイン画面でユーザー ID とパスワードを入れて「ログイン」を押す
2. ログインする前に開こうとしていた画面があれば、その画面が開きます。なければタイムラインが開きます

- 一度ログインすると、**最後に使ってから 14 日間は、ブラウザを閉じてもログインしたまま**です。14 日間使わなかったときは、開くとログイン画面が出るので、ログインし直してください。画面を開いたまま期限が切れて操作したときは「ログインの有効期限が切れました。もう一度ログインしてください。」と出ます
- ユーザー ID は大文字と小文字を区別しません
- **パスワードを 5 回続けて間違えると、そのユーザー ID では 15 分間ログインできません。** 15 分たってから、正しいパスワードでログインしてください

### 2.3 ログアウトする

ヘッダーの「ログアウト」を押します。確認なしでログアウトし、ログイン画面に戻ります。共用のパソコンでは、使い終わったら必ずログアウトしてください。

## 3. タイムライン

ログインすると開く画面です。上から、投稿フォーム・タブ・投稿の一覧が並びます。

### 3.1 タブ

| タブ | 出る投稿 |
| --- | --- |
| フォロー中 | 自分と、フォローしている人の投稿 |
| すべて | 全員の投稿 |

- どちらも新しい順に 20 件ずつ出ます。一番下までスクロールすると続きが出ます。最後まで読むと「これ以上の投稿はありません」と出ます
- タブを押すと、そのタブの最新の投稿から出し直します
- 最後に選んだタブを覚えていて、次に開いたときもそのタブが出ます
- まだ誰もフォローしていないときは「フォロー中」に案内が出ます。「すべて」タブや検索で、フォローする人を探してください

### 3.2 投稿カードの見方

```
┌──────────────────────────────────────────────┐
│ (た) たろう  @taro_y · 3 分前              … │
│      今日は晴れ。川沿いを散歩してきた         │
│      ┌──────────┐ ┌──────────┐               │
│      │ 画像 1   │ │ 画像 2   │               │
│      └──────────┘ └──────────┘               │
│      ♡ 12   💬 3                             │
└──────────────────────────────────────────────┘
```

| 部分 | 意味・できること |
| --- | --- |
| アイコン・表示名・@ユーザー ID | 押すと、その人のプロフィール |
| 3 分前 | 投稿した日時。1 分未満は「たった今」、24 時間以上たつと「10月16日」のように出ます。マウスを乗せると「2026/10/16 15:30」の形で出ます |
| （編集済み） | 投稿した後に本文を直した投稿に出ます。マウスを乗せると直した日時が出ます |
| … | 自分の投稿にだけ出ます。押すと「編集」「削除」（4.3・4.4） |
| 本文 | 押すと投稿の詳細画面（コメントを読む・書く） |
| 画像 | 押すと大きく出ます（4.2） |
| ♡ 12 | いいね（5 章）。数を押すと、いいねした人の一覧 |
| 💬 3 | コメントの数。押すと投稿の詳細画面 |

## 4. 投稿

### 4.1 投稿する

1. タイムラインの上の「いまどうしてる？」に本文を書く
2. 画像を添えるときは「画像を選ぶ」を押して選ぶ
3. 「投稿する」を押す（パソコンでは Ctrl＋Enter、Mac では ⌘＋Enter でも投稿できます）

| 項目 | 決まり |
| --- | --- |
| 本文 | 280 文字まで。Enter キーで改行します。右下に残りの文字数が出て、超えると赤い文字でマイナスになり、投稿できません。前後の空白は取り除きます |
| 画像 | 1 つの投稿に 4 枚まで。JPEG・PNG・GIF・WebP で、1 枚 5MB まで。選んだ画像は小さく並び、右上の「×」で外せます |
| 本文と画像 | どちらか一方があれば投稿できます（画像だけの投稿もできます） |

- 5 枚以上選ぶと、先に選んだ 4 枚だけを添えて「画像は 1 つの投稿に 4 枚までです。」と出ます
- 添えられない画像（5MB を超える・形式が違う）を選ぶと、その画像は添えずにメッセージが出ます
- 投稿は、ログインしている人なら誰でも見られます。見せたくないことは書かないでください

### 4.2 画像を大きく見る

投稿の画像を押すと、画面いっぱいに大きく出ます。

- 画像が 2 枚以上あるときは「‹」「›」（キーボードの左右の矢印キー）で切り替えます。下に「2 / 4」のように何枚目かが出ます
- 「×」、画像の外側、Esc キーで閉じます
- 画像が「画像を読み込めませんでした」になったときは、画面を読み直してください

### 4.3 本文を直す（編集）

1. 自分の投稿の「…」を押して「編集」を押す
2. 本文を直して「保存する」を押す（「キャンセル」か Esc キーで、直す前に戻ります）

- 直せるのは本文だけです。画像は変えられません
- 本文の決まりは投稿するときと同じです。画像のない投稿は、本文を空にできません
- 直した投稿には「（編集済み）」と出ます。タイムラインでの順番・投稿した日時・いいね・コメントはそのままです

### 4.4 削除する

1. 自分の投稿の「…」を押して「削除」を押す
2. 確認の画面で「削除」を押す

**削除すると、画像・コメント・いいねも一緒に消え、元に戻せません。**

## 5. いいね

- 投稿の「♡」を押すと「♥」になり、いいねします。もう一度押すと取り消します。自分の投稿にもいいねできます
- 1 つの投稿にいいねできるのは 1 回だけです。何度押しても、最後に押した状態になります
- いいねの数を押すと、いいねした人の一覧が出ます。一覧からその人をフォローできます
- 誰がいいねしたかは、ログインしている人なら誰でも見られます

## 6. コメント

投稿の本文か 💬 を押すと、投稿の詳細画面が開きます。

```
┌──────────────────────────────────────────┐
│ ← 投稿                                    │
│ （投稿カード）                              │
│ [ コメントを書く                       ]  │
│                       残り 280 [コメントする] │
│ (は) はなこ @hana · 1 分前          削除   │
│      いい天気ですね                       │
└──────────────────────────────────────────┘
```

- **書く**：「コメントを書く」に書いて「コメントする」を押す（Ctrl＋Enter／⌘＋Enter でも送れます）。280 文字まで。画像は添えられません
- **読む**：コメントは古い順に 50 件ずつ出ます。51 件以上あるときは、下の「さらに表示」で続きが出ます
- **消す**：自分のコメントの「削除」を押し、確認の画面で「削除」を押します。コメントは直せません。投稿した人でも、ほかの人のコメントは消せません
- 「←」で前の画面に戻ります

## 7. ユーザーを探す・フォローする

### 7.1 ユーザーを探す

1. ヘッダーの「ユーザーを検索」に、ユーザー ID か表示名の一部を入れる（30 文字まで）
2. Enter キーか 🔍 を押す

- 先頭の「@」は付けても付けなくても同じです。大文字と小文字は区別しません
- ユーザー ID が完全に一致する人 → ユーザー ID がその文字で始まる人 → 表示名がその文字で始まる人 → それ以外、の順に出ます。同じ順位なら、フォロワーの多い人が先です
- 自己紹介と投稿の本文は探しません
- 一致する人がいないときは「「（入れた文字）」に一致するユーザーはいません。」と出ます

### 7.2 フォローする・外す

- ユーザーの行やプロフィールの「フォローする」を押すと「フォロー中」になり、その人の投稿がタイムラインの「フォロー中」タブに出ます
- 「フォロー中」にマウスを乗せると「フォロー解除」になります。押すとフォローを外します（確認は出ません）
- フォローに相手の承認は要りません。自分はフォローできません
- フォローを外しても、その人の投稿にしたいいね・コメントは残ります

## 8. プロフィール

### 8.1 プロフィールを見る

アイコン・表示名を押すと、その人のプロフィールが開きます。

```
┌──────────────────────────────────────────┐
│ (た)  たろう                 [フォローする] │
│       @taro_y                             │
│       川沿いを散歩するのが好きです          │
│       2026年10月から利用                   │
│       フォロー 12   フォロワー 8   投稿 30  │
├──────────────────────────────────────────┤
│ （その人の投稿の一覧）                      │
└──────────────────────────────────────────┘
```

- 「フォロー」「フォロワー」の数を押すと、フォローしている人・フォローされている人の一覧が出ます。上のタブで切り替えられます
- 自分のプロフィールには、フォローボタンの代わりに「プロフィールを編集」が出ます

### 8.2 プロフィールを変える

1. 自分のプロフィールで「プロフィールを編集」を押す
2. 変えて「保存する」を押す（「キャンセル」で変えずに戻ります）

| 項目 | 決まり |
| --- | --- |
| アイコン | 「画像を選ぶ」で選ぶと、丸く切り抜いた形で確認できます。JPEG・PNG・WebP で 5MB まで（GIF は使えません）。「アイコンを外す」で、表示名の 1 文字目を出す丸に戻ります |
| 表示名 | 1〜30 文字 |
| 自己紹介 | 160 文字まで。改行もできます。空にもできます |

- 変えた表示名・アイコンは、過去の投稿やコメントにも出ます
- ユーザー ID とパスワードは変えられません

## 9. メッセージが出たとき

| メッセージ | 原因と、すること |
| --- | --- |
| このユーザー ID は使われています。 | ほかの人が使っています。別の ID にしてください |
| ユーザー ID は 3〜15 文字の半角英数字と「_」で入力してください。 | 決まりに合わせて直してください（2.1） |
| パスワードは英字と数字を含む 8〜64 文字の半角文字で入力してください。 | 同上 |
| パスワード（確認）が一致しません。 | 2 つのパスワードを同じにしてください |
| 表示名を入力してください。 | 表示名を 1 文字以上入れてください |
| ユーザー ID かパスワードが違います。 | 入れ直してください。5 回続けて間違えると 15 分間ログインできなくなります |
| ログインに続けて失敗したため、15 分間ログインできません。 | 15 分たってからログインしてください |
| ログインの有効期限が切れました。もう一度ログインしてください。 | 画面を開いたまま 14 日たったか、ログインの情報が盗まれた疑いがあるため安全のためにログインを切りました。ログインし直してください。心配なときは、すべてのブラウザでログインし直してください |
| 画像は 1 つの投稿に 4 枚までです。 | 先に選んだ 4 枚だけを添えました |
| 添えられるのは 5MB までの JPEG・PNG・GIF・WebP の画像です。 | 別の画像を選んでください |
| アイコンにできるのは 5MB までの JPEG・PNG・WebP の画像です。 | 別の画像を選んでください |
| 投稿に失敗しました。時間をおいてもう一度お試しください。 | 書いた本文と画像は残っています。少し待ってから、もう一度「投稿する」を押してください |
| 操作に失敗しました。時間をおいてもう一度お試しください。 | いいね・フォロー・コメント・削除・保存が届きませんでした。画面は押す前の状態に戻っています。少し待ってからやり直してください |
| 読み込みに失敗しました。時間をおいてもう一度お試しください。 | 「再読み込み」を押してください |
| この投稿は削除されました。 | 投稿した人が削除しました |
| このユーザーは見つかりません。 | ユーザー ID が違うか、その人はいません |
| インターネットに接続されていません。接続を確認してください。 | 機器のインターネットの接続を確かめてください。つながると消えます |
| Raise timeline は止めています | サーバーを止めている時間です。動かしている時間に開き直してください |

## 10. できないこと

- パスワードの再発行、ユーザー ID の変更、退会
- 投稿の画像の差し替え、コメントの編集
- 鍵アカウント、ブロック・ミュート・通報
- 通知、ダイレクトメッセージ、投稿・ハッシュタグの検索
- 日本語以外の表示

不適切な投稿を見つけたときは、運営者に知らせてください。
