## 1. 結論

- 測った項目は、**手元・GitHub Actions のランナーとも、すべて目標以内（合格）** だった。P95 が目標値の 1 割以下に収まる項目がほとんどで、余裕がある
- ただし、どちらも**公開前の参考値**である。要件の合否は公開先（AWS。EC2 t4g.micro・RDS db.t4g.micro）で測って決める（要件定義書 11.1）。公開（開発計画書 3-2c）の後に測り、本書の版数を上げて追記する
- **N-5（ユーザー検索）は API の応答だけを測り、画面に結果が出るまでは測っていない**（6 章）

| 要件 | 内容 | 目標 | ランナーの P95 | 手元の P95 | 判定（参考） |
| --- | --- | --- | --- | --- | --- |
| N-1 | ログインしてからタイムラインの最初の 20 件が表示されるまで | 3 秒以内 | 0.32 秒（スマートフォン 0.56 秒） | 0.47 秒（スマートフォン 0.69 秒） | 合格 |
| N-2 | タイムラインの 20 件を返す API の応答 | 1 秒以内 | 0.05 秒（30 人のとき 0.02 秒） | 0.10 秒（30 人のとき 0.09 秒） | 合格 |
| N-3 | いいね・フォローを押してから画面に反映されるまで | 0.5 秒以内 | 0.14 秒（表示・確定、負荷の有無のうち最も遅いもの） | 0.31 秒（同） | 合格 |
| N-4 | 画像 4 枚（合計 20MB）の投稿を押してから、タイムラインに出るまで | 10 秒以内 | 5.84 秒 | 測っていない（4.3） | 合格（ランナーのみ） |
| N-5 | ユーザー検索の結果が表示されるまで | 1 秒以内 | 0.05 秒（API のみ） | 0.07 秒（API のみ） | API は合格。画面は未測定 |

P95 は、同じ操作を繰り返し測った値を小さい順に並べて 95% の位置の値である（20 回なら遅い方から 2 番目）。

### 4.3 結果から分かったこと

| No | 内容 | 対応 |
| --- | --- | --- |
| 1 | N-4 の 5.8 秒の大部分は、20.3MB を上り 30Mbps で送る時間（計算で約 5.4 秒）だった。サーバーの処理と表示は 0.5 秒程度。上りがこれより遅い回線では 10 秒を超える | 要件定義書 11.1 に「上り 30Mbps 以上」を条件として足した（版数 0.10） |
| 2 | 画像 4 枚が読み込み終わるまでは 22 秒かかる。20MB を下り 10Mbps で読むだけで約 16 秒かかるため | N-1・N-4 は、投稿のカードが出るまでで判定すると決めた（要件定義書 11.1）。画像を小さくして送る・表示する工夫は、要件にないので行わない |
| 3 | 手元では、API から S3（東京）への送信が家の上り回線（約 3Mbps）を通るので、N-4 は 1 回 約 70 秒かかった。公開先（EC2 → S3 は AWS の中）とは条件が違う | 手元の N-4 は、`PERF_UPLOAD=1` を付けたときだけ測る |
| 4 | JS・CSS は圧縮せずに 323KB を配っている（gzip なら約 101KB）。手元・ランナーには CloudFront がないため。公開先では CloudFront が圧縮する見込み | 公開先で測るときに確かめる |
| 5 | パソコンの幅で、タイムラインを開き直すと CLS が 0.079 になる（スマートフォンは 0）。目安の 0.1 以下だが、表示が少しずれている | 原因は調べていない。必要なら別の Issue で調べる |
| 6 | 「♥ が出る」までの時間に、Playwright がボタンの変化を確かめる時間（数十 ms）が含まれる。そのため、応答で確定するまでより遅く出ることがある | 実際より遅めに出るので、合否には影響しない |
| 7 | 30 人の同時アクセスでも、1 人のときより遅くならなかった（ランナーではむしろ速かった。先に 1 人の測定で JIT のコンパイルが進んでいたためと考えられる）。想定する利用者（数十人）では、t4g.micro でも余裕がある見込み | 公開先で確かめる |

## 5. 合否の判定のしかた

要件定義書 11.1 と基本設計書 2.4 のとおり。

| 項目 | 決めたこと |
| --- | --- |
| 判定 | P95 が目標値以内なら合格 |
| 「表示されるまで」（N-1・N-4） | 投稿のカード（文字と画像の枠）が出るまで。画像の読み込みは参考 |
| N-3 | 表示が変わるまでと、応答で確定するまでの両方が 0.5 秒以内 |
| 合否を決める環境 | 公開先（AWS）。本書の値（手元・ランナー）は参考 |
