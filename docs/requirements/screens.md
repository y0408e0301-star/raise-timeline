## 1. 画面一覧

| 画面 ID | 画面名 | URL | 内容 |
| --- | --- | --- | --- |
| G-1 | ログイン画面 | /login | ユーザー ID とパスワードでログインする |
| G-2 | ユーザー登録画面 | /signup | アカウントを作る |
| G-3 | タイムライン画面 | / | 投稿フォーム、「フォロー中」「すべて」のタブ、投稿の一覧 |
| G-4 | 投稿の詳細画面 | /posts/{投稿 ID} | 1 つの投稿と、コメントのフォーム・一覧。自分の投稿はここでも編集・削除できる |
| G-5 | いいねした人の一覧画面 | /posts/{投稿 ID}/likes | その投稿にいいねした人の一覧 |
| G-6 | プロフィール画面 | /users/{ユーザー ID} | ユーザーの情報、フォローボタン、その人の投稿の一覧 |
| G-7 | プロフィールの編集画面 | /settings/profile | アイコン画像・表示名・自己紹介を変える（第 2 版） |
| G-8 | フォロー中・フォロワーの一覧画面 | /users/{ユーザー ID}/following、/users/{ユーザー ID}/followers | 「フォロー中」「フォロワー」のタブとユーザーの一覧 |
| G-9 | ユーザー検索の結果画面 | /search?q={検索した文字} | 検索に一致したユーザーの一覧 |
| G-10 | 画像の拡大ダイアログ | （G-3・G-4・G-6 の上に重ねる） | 投稿の画像を大きく出す |
| G-11 | 確認ダイアログ | （G-4・G-3・G-6 の上に重ねる） | 投稿・コメントを削除する前に確認する |

G-3〜G-9 には共通のヘッダー（アプリ名・ユーザーの検索欄・自分のプロフィール・ログアウト）を出す。

## 2. 画面遷移

```
G-1 ログイン ──ログイン成功──▶ G-3 タイムライン ◀──ヘッダーのアプリ名（どの画面からでも）
  │   ▲                         │
  │   └──────ログアウト──────────┤（どの画面からでも）
  ▼                             ├─本文・コメント数──▶ G-4 投稿の詳細 ──いいね数──▶ G-5 いいねした人
G-2 ユーザー登録 ──登録──▶ G-3   ├─いいね数──────────▶ G-5 いいねした人
                                ├─投稿者名──────────▶ G-6 プロフィール
                                ├─画像──────────────▶ G-10 画像の拡大
                                ├─「…」の編集────────▶ 投稿カードの中で本文を直す（画面は移らない）
                                ├─「…」の削除────────▶ G-11 確認
                                └─ヘッダーの検索欄────▶ G-9 ユーザー検索の結果（どの画面からでも）

G-4・G-5・G-8・G-9 ──名前──▶ G-6 プロフィール
G-6 ──フォロー数・フォロワー数──▶ G-8 フォロー中・フォロワー
G-6 ──プロフィールを編集──▶ G-7 プロフィールの編集 ──保存・キャンセル──▶ G-6（第 2 版）
```

ログイン済みの状態で G-1・G-2 の URL を開いた場合は、G-3 を表示する。

## 3. タイムライン画面（G-3）のイメージ

```
┌──────────────────────────────────────────────────────────────┐
│ Raise timeline     [🔍 ユーザーを検索      ]  プロフィール  ログアウト │
├──────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ いまどうしてる？                                         │ │
│ │ [画像1 ×] [画像2 ×]                                      │ │
│ │ [画像を選ぶ]                             残り 248 [投稿する] │ │
│ └──────────────────────────────────────────────────────────┘ │
│   [ フォロー中 ]   すべて                                     │
├──────────────────────────────────────────────────────────────┤
│ (た) たろう  @taro_y · 3 分前                              … │
│      今日は晴れ。川沿いを散歩してきた                         │
│      ♡ 12   💬 3                                            │
├──────────────────────────────────────────────────────────────┤
│ [写] はなこ  @hana · 10月16日（編集済み）                    │
│      新しいカメラで撮った                                     │
│      ┌────────────┐ ┌────────────┐                           │
│      │  画像 1    │ │  画像 2    │                           │
│      └────────────┘ └────────────┘                           │
│      ♥ 5   💬 0                                              │
└──────────────────────────────────────────────────────────────┘
```

| 部品 | 内容 |
| --- | --- |
| ヘッダー | 左にアプリ名（押すと G-3）、中央にユーザーの検索欄（S-1）、右に自分のプロフィール（G-6）とログアウト |
| 投稿フォーム | 本文・残りの文字数・画像の選択とプレビュー・「投稿する」（W-1〜W-3、I-1〜I-4） |
| タブ | 「フォロー中」「すべて」（T-1）。選んでいるタブに下線を引く |
| 投稿カード | アイコン・表示名・@ユーザー ID・日時・本文・画像・いいね数・コメント数（W-4）。アイコンを設定していない人は頭文字の丸（(た)）、設定した人はその画像（[写]）を丸く出す（PF-10）。編集した投稿は日時の後ろに「（編集済み）」と出す（W-11）。インプレッション数とリツイートのボタンは置かない |
| 「…」 | 自分の投稿にだけ出す。「編集」を選ぶとカードの中で本文を直せる（W-9）。「削除」を選ぶと G-11（W-7） |
| 「♡」「♥」 | いいねの状態（L-1・L-2）。数を押すと G-5 |
| 「💬」 | コメント数。押すと G-4 |
