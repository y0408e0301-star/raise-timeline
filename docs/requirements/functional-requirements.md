## 1. 本書について

利用者がアプリでできること（機能要件）と、画面に表示するメッセージを定める。

- 見出しに「（第 1 版）」「（第 2 版）」と書いたものは、その版で作る。版ごとの範囲は要件定義書 2.1 のとおり
- 画面 ID（G-1 など）は[画面一覧](screens.md)を、データの項目は[データ要件定義書](data-requirements.md)を参照する
- 用語（トリム、文字数、第三者など）は要件定義書 5 章のとおり
- 「誰でも見られる」は、ログインしているユーザーなら誰でも、という意味である（ログインしていない人は何も見られない。N-10）

## 2. 機能要件

### 2.1 ユーザー登録・ログイン（第 1 版）

| ID | 内容 |
| --- | --- |
| A-1 | ユーザー登録画面（G-2）でユーザー ID・表示名・パスワード・パスワード（確認）を入力して「登録する」を押すと、アカウントを作り、ログインした状態でタイムライン画面（G-3）を表示する |
| A-2 | ユーザー ID はトリムした後で 3〜15 文字の半角英数字と「_」とする。英字の大文字・小文字は区別せず、ほかのユーザーと同じものは使えない。条件に合わないときは M-2、使われているときは M-1 を表示する。登録した後は変えられない |
| A-3 | パスワードは 8〜64 文字で、英字と数字を両方含むものとする。条件に合わないときは M-3、パスワード（確認）と一致しないときは M-4 を表示する |
| A-4 | 表示名はトリムした後で 1〜30 文字とする。31 文字目以降は入力できない。0 文字のときは M-5 を表示する |
| A-5 | ログイン画面（G-1）でユーザー ID とパスワードを入力して「ログイン」を押すと、G-3 を表示する。ユーザー ID の英字の大文字・小文字は区別しない |
| A-6 | ユーザー ID またはパスワードが違うときは M-6 を表示する。どちらが違うかは示さない |
| A-7 | 同じユーザー ID で 5 回続けてログインに失敗したら、15 分間そのユーザー ID ではログインできないようにし、M-7 を表示する。ログインに成功したら失敗の回数を 0 に戻す |
| A-8 | 一度ログインすると、最後に操作してから 14 日間は、ブラウザを閉じて開き直してもログインしたままになる。14 日を過ぎて操作したときは M-19 を表示して G-1 に移す |
| A-9 | ヘッダーの「ログアウト」を押すと、確認なしでログアウトし、G-1 に戻る。ログインしていない状態で G-3〜G-9 の URL を開いた場合は G-1 を表示し、ログインした後に開こうとした画面へ移す |

### 2.2 タイムライン（第 1 版）

| ID | 内容 |
| --- | --- |
| T-1 | タイムライン画面（G-3）に「フォロー中」「すべて」の 2 つのタブを出す。「フォロー中」には自分とフォローしている人の投稿を、「すべて」には全ユーザーの投稿を出す |
| T-2 | 投稿は新しい順に 20 件ずつ出す。一番下までスクロールすると、次の 20 件を読み込んで続けて出す。読み込んでいる間は一覧の下に「読み込み中…」と表示する |
| T-3 | G-3 を開いたときは、前回最後に選んでいたタブを出す。初めて開いたときは「フォロー中」を出す。どのタブを選んだかはブラウザに記録する |
| T-4 | 「フォロー中」タブで、誰もフォローしておらず自分の投稿もないときは、一覧の代わりに M-8 を表示する |
| T-5 | 自分が投稿したときは、表示中のタブの一番上にその投稿を足す |
| T-6 | ほかの人の新しい投稿を自動では足さない。タブを押し直すか、画面を読み込み直すと、最新の 20 件から出し直す |
| T-7 | 読み込んでいる途中にほかの人が投稿しても、同じ投稿を 2 回出したり、抜かしたりしない |
| T-8 | 読み込みに失敗したときは M-9 と「再読み込み」ボタンを表示する。「再読み込み」で同じ読み込みをやり直す |

### 2.3 投稿（第 1 版）

| ID | 内容 |
| --- | --- |
| W-1 | G-3 の上の投稿フォームに本文を入力して「投稿する」を押すと投稿する。投稿した後はフォームを空にする |
| W-2 | 本文はトリムした後で 0〜280 文字とする。入力欄の右下に残りの文字数を出し、280 文字を超えたら残りの文字数を赤字の負の数で出して「投稿する」を押せないようにする |
| W-3 | 本文が 0 文字で画像もないときは「投稿する」を押せないようにする。画像が 1 枚以上あれば本文は 0 文字でもよい |
| W-4 | 投稿は「投稿カード」で出す。表示名・@ユーザー ID・投稿日時・本文・画像・いいね数・コメント数を出す。インプレッション数とリツイートのボタンは出さない |
| W-5 | 本文の改行はそのまま出す。URL はリンクにしない。HTML の記号はそのまま文字として出す（N-15） |
| W-6 | 投稿カードの本文またはコメント数を押すと、投稿の詳細画面（G-4）を開く |
| W-7 | 自分の投稿カードにだけ「…」メニューを出す。「削除」を押すと確認ダイアログ（G-11）に M-10 を表示し、「削除」でその投稿と画像・コメント・いいねを削除する。「キャンセル」では何もしない |
| W-8 | 削除された投稿の詳細画面を開いたときは、投稿の代わりに M-11 を表示する |

### 2.4 画像（第 1 版）

| ID | 内容 |
| --- | --- |
| I-1 | 投稿フォームの「画像を選ぶ」を押すと、ファイルを選ぶ画面を開く。選べるのは JPEG・PNG・GIF・WebP で、一度に複数選べる |
| I-2 | 画像は 1 つの投稿に 4 枚までとする。合わせて 5 枚以上を選んだときは、先に選んだ 4 枚だけを添え、M-12 を表示する |
| I-3 | 1 枚 5MB を超える画像、または I-1 以外の形式の画像は添えず、M-13 を表示する。形式は拡張子だけでなく、ファイルの中身でも確かめる |
| I-4 | 選んだ画像は投稿フォームの中に小さく並べて表示し、それぞれの「×」で外せる |
| I-5 | 「投稿する」を押すと、画像を S3 に保存してから投稿する。保存に失敗したときは投稿せず、M-14 を表示する。フォームの本文と画像はそのまま残す |
| I-6 | 投稿カードには、画像を選んだ順にタイル状に並べて出す（1 枚は大きく 1 枚、2〜4 枚は 2 列） |
| I-7 | 画像を押すと、画像の拡大ダイアログ（G-10）で大きく出す。複数あるときは左右の矢印で切り替える。Esc キー・「×」・画像の外側のクリックで閉じる |
| I-8 | 画像の URL は 15 分で使えなくなる（N-14）。画面を開いたまま期限が切れて画像を出せなくなったときは、自動で新しい URL を取り直して出す |

### 2.5 コメント（第 1 版）

| ID | 内容 |
| --- | --- |
| C-1 | G-4 のコメントフォームに本文を入力して「コメントする」を押すと、その投稿にコメントする。コメントの一覧の一番下に足し、フォームを空にする |
| C-2 | 本文はトリムした後で 1〜280 文字とする。残りの文字数の出し方と、押せないときの扱いは W-2・W-3 と同じ |
| C-3 | コメントは古い順に 50 件ずつ出す。51 件以上あるときは一覧の下に「さらに表示」を出し、押すと次の 50 件を出す |
| C-4 | 各コメントには、表示名・@ユーザー ID・コメント日時・本文を出す。表示名を押すとその人のプロフィール画面（G-6）を開く |
| C-5 | 自分のコメントにだけ「削除」を出す。押すと G-11 に M-15 を表示し、「削除」でコメントを削除する。投稿者も、ほかの人が付けたコメントは削除できない |
| C-6 | コメントの中身と件数は誰でも見られる |

### 2.6 いいね（第 1 版）

| ID | 内容 |
| --- | --- |
| L-1 | 投稿カードの「♡」を押すといいねする。「♥」（色付き）に変え、いいね数を 1 増やす |
| L-2 | いいねした投稿の「♥」を押すと、いいねを取り消す。「♡」に戻し、いいね数を 1 減らす |
| L-3 | いいねは 1 人 1 投稿に 1 つまでとする。続けて何回押しても 2 つ以上にはならない |
| L-4 | 自分の投稿にもいいねできる |
| L-5 | いいね数を押すと、いいねした人の一覧画面（G-5）を開く。新しくいいねした順に 20 件ずつ出し、一番下までスクロールすると次の 20 件を出す |
| L-6 | いいね数・コメント数は、画面を表示した時点の値を出す。自分の操作はすぐに反映し、ほかの人の操作は画面を開き直したときに反映する。0 件のときも「0」と出す |

### 2.7 フォロー（第 1 版）

| ID | 内容 |
| --- | --- |
| F-1 | ほかの人のプロフィール画面（G-6）と、ユーザーの一覧（G-5・G-8・G-9）の「フォローする」を押すと、その人をフォローする。ボタンを「フォロー中」に変え、相手のフォロワー数を 1 増やす |
| F-2 | 「フォロー中」ボタンを押すと、確認なしでフォローを外す。マウスを乗せている間は、ボタンの文字を「フォロー解除」に変える |
| F-3 | 相手の承認はいらない。自分自身には「フォローする」ボタンを出さない |
| F-4 | 同じ人を 2 回以上フォローすることはできない |
| F-5 | G-6 にフォロー数とフォロワー数を出す。押すと、フォロー中・フォロワーの一覧画面（G-8）を開く |
| F-6 | G-8 には「フォロー中」「フォロワー」の 2 つのタブを出し、新しくフォローした順に 20 件ずつ出す。フォロー中・フォロワーの一覧と件数は誰でも見られる |
| F-7 | フォローを外しても、その人の投稿に付けたいいね・コメントは残す。外した人の投稿は、次に読み込んだときから「フォロー中」タブに出さない |

### 2.8 ユーザー検索（第 1 版）

| ID | 内容 |
| --- | --- |
| S-1 | ログインした後のすべての画面のヘッダーに、ユーザーの検索欄を出す。入力欄には薄い文字で「ユーザーを検索」と出す |
| S-2 | 検索欄に文字を入力して Enter キーまたは虫めがねのボタンを押すと、ユーザー検索の結果画面（G-9）を開く。G-9 でも同じ検索欄で検索し直せる |
| S-3 | 検索の対象は、ユーザー ID と表示名とする。自己紹介と投稿は対象にしない |
| S-4 | 入力した文字を、ユーザー ID か表示名のどこかに含むユーザーを探す（部分一致）。英字の大文字・小文字は区別しない。先頭の「@」は取り除いてから探す |
| S-5 | 検索する文字はトリムした後で 1〜30 文字とする。31 文字目以降は入力できない。0 文字のときは検索しない |
| S-6 | 結果は次の順に並べる。(1) ユーザー ID が完全に一致する人、(2) ユーザー ID が入力した文字で始まる人、(3) 表示名が入力した文字で始まる人、(4) それ以外で含む人。同じ順位の中はフォロワーの多い順、それも同じならユーザー ID の順とする |
| S-7 | 結果は 20 件ずつ出し、一番下までスクロールすると次の 20 件を出す |
| S-8 | 結果の各行には、表示名・@ユーザー ID・自己紹介の 1 行目と、自分以外には「フォローする／フォロー中」ボタンを出す。行を押すとその人の G-6 を開く。自分も結果に出る |
| S-9 | 一致するユーザーがいないときは M-16 を表示する |

### 2.9 プロフィール

#### 第 1 版

| ID | 内容 |
| --- | --- |
| PF-1 | プロフィール画面（G-6）に、表示名・@ユーザー ID・自己紹介・登録した年月・フォロー数・フォロワー数・投稿数を出す |
| PF-2 | G-6 の下に、その人の投稿を新しい順に 20 件ずつ出す。読み込み方は T-2 と同じ |
| PF-3 | ほかの人の G-6 には「フォローする／フォロー中」ボタンを出す（F-1・F-2）。自分の G-6 には「プロフィールを編集」ボタンを出す（第 2 版） |
| PF-4 | 存在しないユーザー ID の G-6 を開いたときは M-17 を表示する |

#### 第 2 版

| ID | 内容 |
| --- | --- |
| PF-5 | 「プロフィールを編集」を押すと、プロフィールの編集画面（G-7）を開く。表示名と自己紹介を変えて「保存する」を押すと反映し、G-6 に戻る。「キャンセル」では反映せずに G-6 に戻る |
| PF-6 | 表示名の条件は A-4 と同じとする。自己紹介は 0〜160 文字で、改行を入れられる。161 文字目以降は入力できない |
| PF-7 | ユーザー ID とパスワードは G-7 では変えられない |

## 3. メッセージ一覧

| No | 表示する場面 | メッセージ |
| --- | --- | --- |
| M-1 | ユーザー ID が使われている | このユーザー ID は使われています。 |
| M-2 | ユーザー ID が条件に合わない | ユーザー ID は 3〜15 文字の半角英数字と「_」で入力してください。 |
| M-3 | パスワードが条件に合わない | パスワードは英字と数字を含む 8〜64 文字で入力してください。 |
| M-4 | パスワード（確認）が一致しない | パスワード（確認）が一致しません。 |
| M-5 | 表示名が空 | 表示名を入力してください。 |
| M-6 | ログインに失敗 | ユーザー ID かパスワードが違います。 |
| M-7 | ログインの失敗が続いた | ログインに続けて失敗したため、15 分間ログインできません。 |
| M-8 | 「フォロー中」タブに出す投稿がない | まだ誰もフォローしていません。「すべて」タブやユーザー検索で、フォローする人を探してみましょう。 |
| M-9 | 読み込みに失敗 | 読み込みに失敗しました。時間をおいてもう一度お試しください。 |
| M-10 | 投稿の削除の確認 | この投稿を削除しますか？画像・コメント・いいねも削除され、元に戻せません。 |
| M-11 | 削除された投稿を開いた | この投稿は削除されました。 |
| M-12 | 画像が 5 枚以上 | 画像は 1 つの投稿に 4 枚までです。 |
| M-13 | 添えられない画像 | 添えられるのは 5MB までの JPEG・PNG・GIF・WebP の画像です。 |
| M-14 | 投稿に失敗 | 投稿に失敗しました。時間をおいてもう一度お試しください。 |
| M-15 | コメントの削除の確認 | このコメントを削除しますか？ |
| M-16 | 検索の結果が 0 件 | 「（検索した文字）」に一致するユーザーはいません。 |
| M-17 | 存在しないユーザー | このユーザーは見つかりません。 |
| M-18 | いいね・フォロー・コメント・削除・保存に失敗 | 操作に失敗しました。時間をおいてもう一度お試しください。 |
| M-19 | ログインの期限切れ | ログインの有効期限が切れました。もう一度ログインしてください。 |
| M-20 | 通信切れ | インターネットに接続されていません。接続を確認してください。 |

M-18 を表示するときは、画面をその操作の前の状態に戻す（例：いいねに失敗したら「♡」といいね数を元に戻す）。M-20 は、インターネットに接続できないことに気づいたときに表示し、接続が戻ったら消す。
