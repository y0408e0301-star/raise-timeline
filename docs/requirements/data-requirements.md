## 1. ユーザー

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける。重複しない。画面には出さない |
| ユーザー ID | 文字列 | ○ | トリム後 3〜15 文字の半角英数字と「_」。大文字・小文字を区別せずに重複しない。変更できない |
| 表示名 | 文字列 | ○ | トリム後 1〜30 文字 |
| パスワード | 文字列 | ○ | 8〜64 文字、英字と数字を両方含む。元に戻せない形で保存する（N-12） |
| 自己紹介 | 文字列 | | 0〜160 文字。改行を含められる |
| アイコン画像 | 画像 | | JPEG・PNG・WebP で 5MB まで。ファイルは S3 に置き、データベースには置き場所だけを持つ（P-2）。設定していないときは表示名の頭文字を出す（第 2 版） |
| ログインの失敗回数 | 数値 | ○ | 続けて失敗した回数（A-7） |
| ログインできない期限 | 日時 | | 5 回続けて失敗したときの 15 分後（A-7） |
| 登録日時 | 日時 | ○ | 自動で記録 |
| 更新日時 | 日時 | ○ | 自動で記録 |

## 2. 投稿

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける。重複しない。新しい投稿ほど大きい |
| 投稿者 | ユーザー | ○ | 投稿したユーザー |
| 本文 | 文字列 | ○ | トリム後 0〜280 文字。画像がないときは 1 文字以上 |
| 投稿日時 | 日時 | ○ | 自動で記録 |
| 編集日時 | 日時 | | 最後に本文を編集した日時。編集していない投稿にはない（W-11） |

投稿で編集できるのは本文だけで、画像は変えられない（W-9）。

## 3. 画像

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける |
| 投稿 | 投稿 | ○ | 画像を添えた投稿 |
| 置き場所 | 文字列 | ○ | S3 の中での場所（キー）。重複しない。元のファイル名は使わない |
| 形式 | 文字列 | ○ | JPEG・PNG・GIF・WebP のどれか |
| 大きさ | 数値 | ○ | バイト数。5MB（5,242,880 バイト）以下 |
| 並び順 | 数値 | ○ | 選んだ順に 0〜3 |

画像のファイルそのものは S3 に置き、データベースには上の項目だけを持つ（P-2）。

## 4. コメント

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける |
| 投稿 | 投稿 | ○ | コメント先の投稿 |
| コメントした人 | ユーザー | ○ | |
| 本文 | 文字列 | ○ | トリム後 1〜280 文字 |
| コメント日時 | 日時 | ○ | 自動で記録 |

## 5. いいね

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| いいねした人 | ユーザー | ○ | |
| 投稿 | 投稿 | ○ | いいねした投稿。いいねした人と投稿の組み合わせは重複しない（L-3） |
| いいねした日時 | 日時 | ○ | 自動で記録。G-5 の並び順に使う |

## 6. フォロー

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| フォローした人 | ユーザー | ○ | |
| フォローされた人 | ユーザー | ○ | フォローした人と同じ人にはできない（F-3）。組み合わせは重複しない（F-4） |
| フォローした日時 | 日時 | ○ | 自動で記録。G-8 の並び順に使う |

## 7. リフレッシュトークン

ログインしたままにする（A-8）ために、ログインした人に渡す文字列である。JWT（N-25）の有効期限が切れたときに、これを使って新しい JWT を受け取る。

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ユーザー | ユーザー | ○ | ログインした人。1 人が複数のブラウザでログインしたときは、ブラウザごとに 1 つ持つ |
| トークン | 文字列 | ○ | 推測できない長い文字列。データベースには元に戻せない形（ハッシュ）で保存する |
| 有効期限 | 日時 | ○ | 発行してから 14 日後（A-8） |
| 無効にした日時 | 日時 | | 使って新しいものに替えたとき、ログアウトしたときに記録する |
| 発行日時 | 日時 | ○ | 自動で記録 |

有効期限を過ぎたものは、1 日 1 回まとめて消す。

## 8. 上限

| 対象 | 上限 |
| --- | --- |
| 投稿の本文 | 280 文字 |
| コメントの本文 | 280 文字 |
| 1 つの投稿の画像 | 4 枚 |
| 画像 1 枚の大きさ | 5MB |
| アイコン画像の大きさ | 5MB |
| 自己紹介 | 160 文字 |
| 検索する文字 | 30 文字 |
| ユーザー・投稿・コメント・いいね・フォローの件数 | 上限なし（性能の目標は N-1〜N-5 の条件で確かめる） |

## 9. 詳細

データの詳しい構造（ER 図）は[データ設計書](../design/data-design.md)で定める。

## 10. 保存する個人情報

ユーザー ID・表示名・自己紹介・アイコン画像と、元に戻せない形にしたパスワードのみを保存する。アイコン画像も、ログインした全員に見える。メールアドレス・本名・電話番号は保存しない。投稿・コメント・画像は利用者が自分で公開するものとして扱い、ログインした全員に見える（要件定義書 3.1）。
